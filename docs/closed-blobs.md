## Reading

- The DWARF is enough to document interfaces, function names, line-level behaviour and data layout, and to cross-reference which upstream files were withheld.
- The prebuilt part is not a thin shim: the multimedia archive alone exports thousands of symbols and holds ~1.1 MB of code per variant.
- Third-party licensed code sits inside the blobs (Fraunhofer FDK-AAC under `services/multimedia/audio/codec/fdkaac_codec`, Savitech LHDC, Sony LDAC), so those parts cannot be relicensed as open source regardless of what BES decides.
- Reimplementing code learned from these blobs is still reverse engineering of BES proprietary code; it does not create an open-source licence for the result.
